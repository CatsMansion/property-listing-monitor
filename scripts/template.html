房源监测

条件： · 数据源 allhomes + realestate.com.au · 更新于
关于数据
· 两个来源：allhomes.com.au（Domain 集团，堪培拉本地主站）+ realestate.com.au（REA 集团，独立公司，不是同一批数据）。
· 同一套房在两个站都登了会合并成一行，标「双源」并给出两个链接；价格取能证明在预算内的那一个。
· 两家都不支持按卧室/卫生间筛（allhomes 参数被忽略，REA 只认路径里的卧室段、会丢掉卫浴段）， 所以卧卫一律由本工具本地过滤。
· 固定价 = 报价或区间上限 ≤ $700k；起价 = 「$659,000+」这种下限，能谈但有涨的余地； 价格待核实 = 拍卖 / 议价 / 未公开价。
· 这类房源没有中介指导价（实测 52 套里 52 套的 priceGuide 都是空，页面自己写着 "This agent hasn't provided a price guide yet"）。价目里那行小字「估值」是 allhomes 自己的自动估值模型，不是业主要价，只能拿来判断「值不值得打电话」， 不能当报价依据。标「估值够得着」= 估值下限仍在预算内。
· 价格右边那列百分比 = 季度 strata × 4 ÷ 房价，即每年物业费占房价的比例，超过 1.5% 标红。 数字只从广告正文里抠（站方没有结构化字段），抠不到就显示 —，不是 0； 拍卖/议价没有公开报价，算不出比例，那一列改显示季度金额。
· 本页为本地看板，数据由监测脚本写入。刷新数据请运行 python monitor.py。
